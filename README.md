# jarrettd.com

Source for [jarrettd.com](https://jarrettd.com): a static, hardened personal portfolio built with Astro and hosted at the edge. No server code, no third-party requests at runtime, and a strict Content Security Policy.

Rules, commands and build checks are in [CONTRIBUTING.md](CONTRIBUTING.md). The short version:

```
npm ci --ignore-scripts
npm run verify
```

Built, tested, and hardened with help from Claude Code and Codex.

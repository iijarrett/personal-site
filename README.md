# jarrettd.com

[![CI](https://github.com/iijarrett/personal-site/actions/workflows/ci.yml/badge.svg)](https://github.com/iijarrett/personal-site/actions/workflows/ci.yml) [![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/iijarrett/personal-site/badge)](https://scorecard.dev/viewer/?uri=github.com/iijarrett/personal-site)

Source for [jarrettd.com](https://jarrettd.com): a static, hardened personal portfolio built with Astro and hosted at the edge. No server code, no third-party requests at runtime, and a strict Content Security Policy.

Rules, commands and build checks are in [CONTRIBUTING.md](CONTRIBUTING.md). The short version:

```
npm ci --ignore-scripts
npm run verify
```
